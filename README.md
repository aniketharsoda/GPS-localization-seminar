# 📍 GPS Localization System

> Scientific seminar project using an **Arduino Mega 2560** and a **u-blox NEO-6M GPS module** for real-time 3D object positioning, NMEA sentence parsing, and edge-computing geofencing.

---

### ⚡ Key Features & Field Test Results
* **Stable 3D Fix:** Tracked 6 active satellites at TH Ingolstadt campus.
* **Recorded Position:** `48.767002° N`, `11.433200° E`, `375.10 m` altitude.
* **Accuracy:** 6-decimal precision (~11.1 cm mathematical resolution / 2.5 m CEP physical accuracy).
* **Concepts:** NMEA Parsing, Time-of-Arrival (TOA), Equirectangular Geofencing, VDOP Analysis.
